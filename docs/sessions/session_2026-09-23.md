## 1. MỤC TIÊU 1: CHẨN ĐOÁN LỖI WEBSOCKET SIGNALR 414

### 1.1 Hiện tượng lỗi
```
WebSocket connection to 'ws://172.26.68.16:1993/api/hubs/notifications?id=...&access_token=eyJ...(13KB)...'
failed: Error during WebSocket handshake: Unexpected response code: 414
```

### 1.2 Phân tích Nguyên nhân Gốc Rễ
| Tầng | Vấn đề |
|---|---|
| **TokenService.cs** | `GenerateAccessToken()` nhét toàn bộ `IEnumerable<ProgramMenuPermissionResponseDto>` vào claim `permissions` — mỗi entry chứa 11 fields (ProgramId, ProgramKey, ProgramName, Path, Icon, ApiUrl, Level, SortOrder, IsSearch, IsCreate, ...) |
| **AuthService.cs** | `JsonSerializer.Serialize(authorizedMenus)` tại 3 nơi (Login, RefreshToken, ForceChangePassword) → chuỗi JSON 8-13KB |
| **SignalR WebSocket** | Bắt buộc truyền `access_token` qua URL query string `?access_token=...` khi WebSocket handshake |
| **Kestrel** | `MaxRequestLineSize` mặc định = 8KB → URL vượt giới hạn → **HTTP 414** |
| **Nginx** | Buffer `server` block (64k/128k) đã được cấu hình trong phiên 22/09, nhưng không đủ vì lỗi xảy ra ở Kestrel |

### 1.3 Bằng chứng xác nhận kích thước token
Token JWT thực tế decode được tại console trình duyệt cho thấy claim `permissions` chứa JSON array đầy đủ toàn bộ menu tree với metadata giao diện, tổng kích thước 13,607 ký tự.

## 2. MỤC TIÊU 2: TỐI ƯU HÓA JWT ACCESS TOKEN — COMPACT BITMASK PERMISSIONS

### 2.1 Giải pháp Thiết kế

**Trước (JSON đầy đủ ~8-13KB)**:
```json
[
  {
    "programId": 1003,
    "programKey": "USER_MANAGEMENT",
    "parentProgramKey": "1000",
    "programName": "Quản lý Người dùng",
    "level": 2,
    "sortOrder": 10,
    "path": "/users/list",
    "icon": "UserOutlined",
    "apiUrl": "/api/users",
    "isSearch": true,
    "isCreate": true,
    "isUpdate": true,
    "isDelete": true,
    "isSave": true,
    "isPrint": true
  },
  ...
]
```

**Sau (Compact Bitmask < 500 bytes)**:
```json
{"USER_MANAGEMENT":63,"2004_PAYROLL":55,"MEAL_MANAGEMENT":33,...}
```

### 2.2 Bitmask Encoding
| Flag | Bit | Value | Mô tả |
|---|---|---|---|
| `IsSearch` | 0 | 1 | Quyền xem/tìm kiếm |
| `IsCreate` | 1 | 2 | Quyền tạo mới |
| `IsUpdate` | 2 | 4 | Quyền cập nhật |
| `IsDelete` | 3 | 8 | Quyền xóa |
| `IsSave`   | 4 | 16 | Quyền lưu |
| `IsPrint`  | 5 | 32 | Quyền in/xuất |

Ví dụ: `63 = 0b00111111` = toàn quyền; `1 = 0b00000001` = chỉ xem.

### 2.3 Triển khai Kỹ thuật

#### TokenService.cs — 2 Static Helper Methods Mới:
```csharp
// Chuyển IEnumerable<ProgramMenuPermissionResponseDto> → compact JSON
public static string BuildCompactPermissionsJson(IEnumerable<ProgramMenuPermissionResponseDto> permissions)

// Kiểm tra bitmask cho một programKey + permissionFlag cụ thể
public static bool CheckCompactPermission(string compactPermissionsJson, string programKey, string permissionFlag)
```

#### AuthService.cs — Cập nhật 3 vị trí:
- `LoginAsync()`: Compact permissions cho JWT khi đăng nhập
- `RefreshTokenAsync()`: Compact permissions cho JWT sau rotation
- `ForceChangePasswordAsync()`: Compact permissions cho JWT sau đổi mật khẩu bắt buộc

### 2.4 Kết quả Giảm Kích thước Token

| Thành phần | Trước | Sau | Giảm |
|---|---|---|---|
| Claim `permissions` | 8,000 – 13,607 bytes | ~300 – 500 bytes | **97%** |
| JWT Access Token tổng | ~10 – 14 KB | **~1 KB** | **~90%** |
| WebSocket Handshake URL | >8 KB → **Error 414** | ~1.5 KB → **✅ OK** | Giải quyết triệt để |

## 3. MỤC TIÊU 3: CẬP NHẬT PERMISSIONATTRIBUTE — ĐỌC COMPACT BITMASK

### 3.1 Thay đổi Logic

**PermissionAttribute.cs** được cập nhật để đọc compact bitmask format mới, đồng thời giữ toàn bộ tính tương thích ngược:

```csharp
public void OnAuthorization(AuthorizationFilterContext context)
{
    // [1] Admin bypass: Pass ngay nếu user đã đăng nhập hợp lệ (giữ nguyên)
    if (!string.IsNullOrEmpty(userCode)) return;

    // [2] Đọc compact bitmask format mới (PRIMARY)
    if (TokenService.CheckCompactPermission(permissionsJson, _programKey, _permissionFlag))
        return;

    // [3] Fallback: đọc format cũ JSON array (BACKWARD COMPATIBILITY)
    // — dành cho token cũ chưa được refresh sang compact format
    var permissions = JsonSerializer.Deserialize<List<ProgramMenuPermissionResponseDto>>(...);
    // ... logic cũ
}
```

### 4.1 Program.cs — Kestrel Limits
```csharp
builder.WebHost.ConfigureKestrel(options =>
{
    options.Limits.MaxRequestLineSize = 32 * 1024;       // 32KB (mặc định 8KB)
```
