## 7. TÁI CẤU TRÚC VÀ CHUẨN HÓA TRẠNG THÁI TÀI KHOẢN (STATUS: 1 ACTIVE - 2 LOCKED - 0 DELETED)

### 7.1 Quy Ước 3 Trạng Thái Chuẩn (User Status Enum)
- **Status = 1: 🟢 Đang hoạt động (Active):** Tài khoản bình thường, được phép đăng nhập và sử dụng hệ thống.
- **Status = 2: 🔒 Bị khóa (Locked):** Tài khoản bị khóa do Admin chủ động khóa hoặc do người dùng nhập sai mật khẩu quá 5 lần liên tiếp.
- **Status = 0: 🗑️ Đã xóa / Nghỉ việc (Deleted):** Tài khoản bị xóa mềm khỏi hệ thống.

### 7.2 Backend Logic (.NET 8)
1. **Xác thực Đăng nhập (`AuthService.cs` & `AuthRepository.cs`):**
   - Khi nhập sai mật khẩu đến lần thứ 5: Tự động cập nhật `Status = 2` (Locked) và ghi log `ACCOUNT_LOCKED_AUTO`.
   - Khi đăng nhập:
     * Nếu `Status == 2`: Từ chối đăng nhập với thông báo rõ ràng: *"Tài khoản của bạn đang bị KHÓA do nhập sai mật khẩu 5 lần hoặc do Quản trị viên khóa! Vui lòng liên hệ Admin để mở khóa."*
     * Nếu `Status == 0`: Từ chối đăng nhập với thông báo: *"Tài khoản không tồn tại hoặc đã bị XÓA khỏi hệ thống!"*
     * Chỉ cho phép đăng nhập khi `Status == 1`.
2. **Quản trị Tài khoản (`UsersController.cs` & `UsersService.cs` & `UserRepository.cs`):**
   - `PUT /api/users/{id:guid}/toggle-lock`: Đổi trạng thái giữa `Status = 1` và `Status = 2` (khi mở khóa về 1 thì reset `Comment = "0"`).
   - `DELETE /api/users/{id:guid}`: Xóa mềm đơn lẻ (`Status = 0`).
   - `PUT /api/users/{id:guid}/restore`: Phục hồi đơn lẻ về `Status = 1` (reset `Comment = "0"`).
   - `POST /api/users/{id:guid}/reset-password`: Reset mật khẩu đơn lẻ về `Hansol@12345`, `MustChangePassword = 1`, `Status = 1`, `Comment = "0"`.
   - `POST /api/users/batch-reset-password`: Reset mật khẩu hàng loạt về `Hansol@12345`, `MustChangePassword = 1`, `Status = 1`, `Comment = "0"`.
   - `POST /api/users/batch-unlock`: Mở khóa hàng loạt về `Status = 1`, `Comment = "0"`.
3. **Truy vấn SQL (`UserQueries.sql`):**
   - Mệnh đề lọc `WHERE (@Status IS NULL OR u.Status = @Status)` xử lý chuẩn xác cả 3 giá trị 0, 1, 2.

### 7.3 Frontend UI (`src/pages/Users/List/index.tsx`)
1. **Bộ lọc Trạng thái (Filter Dropdown):** 4 lựa chọn rõ ràng:
   - Tất cả Trạng thái (All) -> `value: undefined`
   - 🟢 Đang hoạt động (Active) -> `value: 1`
