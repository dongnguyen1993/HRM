### 2.2 Quyết định kiến trúc đã thống nhất (không cần thay đổi)

| Quyết định | Lý do giữ nguyên |
|---|---|
| **Dapper + Raw SQL** thay vì EF Core | SQL phức tạp cho nghiệp vụ chấm công, tách file .sql riêng dễ maintain |
| **Dual-Key Pattern** (UserId + SecureId) | Hiệu năng JOIN nội bộ (INT) + bảo mật API URL (GUID) |
| **Denormalization WorkSummary** (lưu UserCode, FullName, UserGroup) | Tránh JOIN khi xuất báo cáo hàng triệu dòng |
| **Silent Refresh Token** (HttpOnly Cookie + Rotation) | Bảo mật cao, chống XSS, cơ chế đúng RFC 6749 |
| **BioStar 2 Daily Sync Worker** (09:15 AM) | Tích hợp thiết bị phần cứng, không thể real-time |
| **sp_CalculateTimesheetEngine** là Stored Procedure | Logic nghiệp vụ phức tạp, cần transaction nguyên tử |
| **Composite PK** cho AuthorGroupMapping (GroupId+ProgramId) | Đảm bảo duy nhất ma trận quyền |
