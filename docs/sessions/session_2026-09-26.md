### 1.1 Sửa lỗi 500 & Mã hóa Font Chữ Tiếng Việt Sheet 'Cơm Hàn'
- **Hiện tượng:** Khi bấm nút "Xuất Phiếu Báo Cơm (Excel)", hệ thống báo lỗi 500 Internal Server Error tại endpoint `GET /api/meal-orders/admin/export-excel`. Đồng thời, tại sheet 'Cơm Hàn', tiêu đề các cột thứ bị lỗi font UTF-8 nghiêm trọng (`Thá»© TÆ°`, `Thá»© NÄƒm`...).
- **Xử lý:**
  - Chuẩn hóa lại phương thức xuất báo cáo trong `MealOrderService.cs` với ClosedXML.
  - Loại bỏ hoàn toàn việc parse thủ công `Encoding.Default` hoặc `Encoding.UTF8.GetString(...)`.
  - Thay thế bằng hàm tiện ích chuẩn `GetDayOfWeekVietnamese(date)` trả về trực tiếp chuỗi Unicode chuẩn ("Thứ Hai", "Thứ Ba", "Thứ Tư", "Thứ Năm", "Thứ Sáu", "Thứ Bảy", "Chủ Nhật"), tương thích 100% trên cả Windows và Linux Docker Container.

### 1.2 Phân Quyền Người Dùng: 1 User Có Thể Đặt Cơm Cho Nhiều Phòng Ban

  - Tự động map danh sách mã phòng ban `mealDepartmentCodes: string[]`.
- **Backend & Database:**
  - Thiết kế bảng quan hệ `User_Meal_Departments (UserId, DepartmentCode, CreatedAt, CreatedBy)` với khóa ngoại và index tối ưu.

### 1.3 Tách Bảng Giao Diện Độc Lập `User_Theme_Settings`
- **Mục tiêu:** Tách các thông số tùy chọn giao diện khỏi bảng chính `Users` để chuẩn hóa CSDL (3NF) và giúp bảo trì độc lập.

- **Backend:**
  - Tạo Entity `UserThemeSettings.cs`, DTO `UserPreferencesDto`, `UserPreferencesRequest`.
  - Bổ sung Repository & API `GET /api/users/preferences` và `POST /api/users/preferences`.

### 1.4 Khắc Phục Lỗi Màn Hình Quản Lý Người Dùng Bị Trống & Bổ Sung Dữ Liệu

### 2.4 Sửa Triệt Để Lỗi Infinite Re-render Loop & Skeleton Loading Màn Hình WorkCalendar
- **Hiện tượng:** Màn hình `WorkCalendar` bị nhấp nháy/giật liên tục và bị kẹt cứng ở thanh Skeleton loading màu xám, không hiển thị lịch.
- **Nguyên nhân cốt lõi:**
  - Hàm dịch `t` được khai báo dạng inline function trong body hook: `const t = (id, def, val) => intl.formatMessage(...)`. Mỗi lần render, hàm `t` sinh ra một tham chiếu con trỏ mới.
  - `fetchCalendar` được khai báo qua `useCallback(..., [t])` nên phụ thuộc vào `t`. Kết quả là `fetchCalendar` bị tái tạo lại liên tục trên mọi lượt render.
  - `useEffect([currentMonth, fetchCalendar])` thấy `fetchCalendar` đổi tham chiếu -> kích hoạt gọi API -> cập nhật `loading` và `calendarData` -> Component re-render -> lại sinh `t` mới -> **VÒNG LẶP VÔ HẠN (Infinite Re-render Loop)**.
- **Khắc phục triệt để:**
  - Bọc `t` bằng `useCallback(..., [intl])`.
  - Tách `fetchCalendar` hoàn toàn khỏi `t`, chỉ phụ thuộc `[intl]`.
  - Tạo khóa tháng `monthKey = useMemo(() => currentMonth.format('YYYY-MM'), [currentMonth])` và ràng buộc `useEffect` theo `[monthKey, fetchCalendar]`.
  - Bọc toàn bộ các hàm sự kiện qua `useCallback` và các biến phân quyền qua `useMemo`.
  - Cập nhật dev proxy trong `.umirc.ts` trỏ đúng cổng backend Docker `7014`.
